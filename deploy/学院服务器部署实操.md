## 一、GitHub Actions 造离线依赖包

1. 项目仓库加 `.github/workflows/build-offline-wheels.yml`:

```yaml
name: Build Offline Wheels
on:
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"        # 必须与服务器一致
      - run: python -m pip install --upgrade pip wheel
      - run: |
          mkdir -p offline_wheels
          pip download --dest offline_wheels --prefer-binary \
            --extra-index-url https://download.pytorch.org/whl/cpu \
            -r requirements.txt
          pip download --dest offline_wheels --prefer-binary pip setuptools wheel
      - uses: actions/upload-artifact@v4
        with:
          name: offline-wheels
          path: offline_wheels/
```

2. 推送后:GitHub 仓库 → **Actions** → 选该 workflow → **Run workflow**
3. 跑完进入该次运行,底部 **Artifacts** 下载 `offline-wheels`(zip),本地解压

> 关键:`python-version` 必须 3.12;**不要**加 `--platform`/`--only-binary=:all:`(会报 No matching distribution)。
> 有 PyTorch 的 `--extra-index-url .../cpu` 拉 CPU 版,省几个 G。

## 二、本地打包(在项目根目录)

```bash
# 代码包(排除 .venv/node_modules/.git/.env)
tar -czf app-code.tar.gz --exclude=.venv --exclude=node_modules --exclude=.git --exclude=.env .

# 依赖包(解压后的 offline_wheels 目录)
tar -czf offline_wheels.tar.gz offline_wheels

# 前端产物(本地 npm run build 后)
tar -czf dist.tar.gz -C 前端目录 dist

# HuggingFace 模型:用 -L 解符号链接导出再打包(直接打包会断链)
cp -rL ~/.cache/huggingface/hub/models--BAAI--bge-m3/snapshots/<快照ID> ./模型目录
tar -czf model.tar.gz 模型目录
```

> 数据库等数据文件直接传,无需打包。

## 五、离线安装

```bash
cd /home/ai4edu/L2/项目名
python3 -m venv .venv
./.venv/bin/python -m pip install --no-index --find-links=offline_wheels -r requirements.txt
```

> `--no-index` = 完全不联网,只从本地 wheel 目录装。
> 若报 `ensurepip is not available`:找老师 `sudo apt install python3-venv` 装一次。

## 六、配置 .env(千问 + 模型路径)

```bash
printf 'VLLM_BASE_URL=http://localhost:9002/v1\nVLLM_MODEL_NAME=Qwen3-8B\nVLLM_API_KEY=sk-anything\nVLLM_TEMPERATURE=0.0\nLLM_JSON_MODE=true\nEMBEDDING_MODEL_PATH=/home/ai4edu/L2/项目名/模型目录\nDATABASE_URL=sqlite:///./data/app.db\n' > .env
cat .env
```

> 用 `printf` 写 .env,**别用 heredoc**(粘贴时缩进会让 EOF 失效,且 `\f` 等易被吞)。

## 七、启动

```bash
# 先杀掉可能残留的旧进程,避免 address already in use
pkill -f "uvicorn app.main"; sleep 2

# 启动(8000 被 vLLM 占,用 8088;--host 0.0.0.0 才能外部访问)
cd /home/ai4edu/L2/项目名
./.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8088
```

等日志 `RAG 预热完成` 即就绪。后台常驻:

```bash
nohup ./.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8088 > run.log 2>&1 &
tail -f run.log        # 看日志
pkill -f "uvicorn app.main"   # 停止
```

## 坑速查

| 现象 | 解决 |
|------|------|
| `SSLError: self-signed certificate` | 校园网认证拦截,放弃在线 pip,走离线 wheel |
| `No matching distribution` | workflow 别加 `--platform`/`--only-binary`;或 python 版本不一致 |
| `ensurepip is not available` | 找老师 `sudo apt install python3-venv` |
| `address already in use` | `pkill -f uvicorn` 后重启,或换端口 |
| 外部连不上 | 用第八节 SSH 隧道,或找管理员放行端口 |
| 模型加载失败 | 确认 `cp -rL` 导出过(解了符号链接),.env 的 `EMBEDDING_MODEL_PATH` 路径对 |
| 公式显示乱码(\f→↑) | choices 的 JSON 转义损坏,`\frac` 要写成 `\\frac` |
