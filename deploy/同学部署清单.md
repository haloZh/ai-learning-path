## 目标目录

## 待传的三个包(本地已备好)

| 包 | 内容 | 大小 |
|----|------|------|

## 一、本地:传文件到服务器(本地 PowerShell / 终端执行)

先传到家目录 `~`(scp 默认落点),解压时再放到工作空间。

```bash
# 1) 代码包(快)
scp -P 60042 D:\code\app-code.tar.gz L2@222.199.207.10:~/

# 2) 模型包(1.3G,较慢,看上传带宽可能十几分钟)
scp -P 60042 D:\code\bge-m3-model.tar.gz L2@222.199.207.10:~/

# 3) Python 依赖包(先把 GitHub 下载的 offline_wheels 目录压成 tar 再传)
scp -P 60042 D:\code\offline_wheels.tar.gz L2@222.199.207.10:~/
```

---

## 二、服务器:解压到工作空间(SSH 登录后执行)

```bash
ssh -p 60042 L2@222.199.207.10

# 解压代码到工作空间
mkdir -p /home/ai4edu/L2
tar -xzf ~/app-code.tar.gz -C /home/ai4edu/L2/
# 此时得到 /home/ai4edu/L2/ai-learning-path/

cd /home/ai4edu/L2/ai-learning-path

# 模型和依赖解压到项目内
tar -xzf ~/bge-m3-model.tar.gz -C .       # -> bge-m3-model/
tar -xzf ~/offline_wheels.tar.gz -C .     # -> offline_wheels/
```

解压后目录结构:

```
/home/ai4edu/L2/ai-learning-path/
├── app/                 # 后端代码
├── ymy/dist/            # 前端产物(已构建,服务器无需 Node)
├── data/app.db          # 数据库(33概念/389题/33资源)
├── data/chroma/         # 向量索引
├── bge-m3-model/        # 向量模型
├── offline_wheels/      # Python 依赖 wheel
├── deploy/offline_install.sh
└── requirements.txt
```

---

## 三、服务器:离线安装

```bash
cd /home/ai4edu/L2/ai-learning-path
bash deploy/offline_install.sh
```

脚本会:建 venv → `pip install --no-index` 离线装依赖 → 检查模型/前端。

---

## 四、配置 .env

```bash
nano .env
```

确认以下内容(千问在本机直连):

```ini
VLLM_BASE_URL=http://localhost:9002/v1
VLLM_MODEL_NAME=Qwen3-8B
VLLM_API_KEY=sk-anything
LLM_JSON_MODE=true
EMBEDDING_MODEL_PATH=/home/ai4edu/L2/ai-learning-path/bge-m3-model
DATABASE_URL=sqlite:///./data/app.db
```

---

## 五、启动

> ⚠️ vLLM 已占用 8000 端口,本项目用 **8088**(或其他空闲端口)。

```bash
cd /home/ai4edu/L2/ai-learning-path
./.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8088
```

- 首次启动等 1-2 分钟(加载 bge-m3),日志出现 `RAG 预热完成` 即就绪
- 浏览器访问:**http://222.199.207.10:8088**
- 若访问不了:确认服务器防火墙/安全组放行 8088 端口

cd /home/ai4edu/L2/ai-learning-path

## 排错

| 现象 | 解决 |
|------|------|
| pip 离线装报缺包 | offline_wheels 不全,重跑 GitHub Actions 确认所有依赖下载 |
| 诊断显示 "Mock 兜底" | 千问没连上,`curl http://localhost:9002/v1/models` 确认通;查 .env |
| 报 response_format 不支持 | .env 设 `LLM_JSON_MODE=false` 重启 |
| RAG 不可用 | 确认 bge-m3-model 解压了且 .env 的 EMBEDDING_MODEL_PATH 路径对 |
| 访问不了网页 | 端口防火墙/安全组未放行 8088 |
