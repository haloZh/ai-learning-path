## 一、系统概述

本系统面向**管综数学基础**备考场景，用"诊断 — 生成 — 调整"的闭环替代在线学习平台"千人一面"的资源分发模式。整套流程通过一个 **Web 网页**呈现，浏览器打开即用、免安装、跨设备。

核心特色：

- **多智能体协作**：诊断 / 规划 / 评价 / 优化 四个 Agent 各司其职，由 LangGraph 编排；
- **检索增强（RAG）**：bge-m3 向量检索 + Chroma 向量库，为路径匹配真实学习资源；
- **可解释决策**：每一步推荐都附"为什么这样推荐"，区别于黑盒问答；
- **闭环动态调整**：学习过程中根据反馈实时优化后续路径；
- **量化评估**：诊断结果与路径质量均有客观指标量化呈现。

系统采用左侧导航 + 主内容区的布局，**五个功能页按学习闭环顺序排列**，并通过"步骤锁定"机制引导用户依序完成——未完成前置步骤时，后续菜单显示锁图标且不可点击。

---

## 二、整体使用流程

```
①画像录入  →  ②诊断测验  →  ③路径视图  →  ④学习工作台  →  ⑤评估看板
   |             |              |               |                |
 建立学生     答题量化       生成个性化       按路径学习      回看学习
   画像        掌握度          学习路径        + 反馈调整        全貌评估
```

整个闭环对应后端的两条智能体链路：

- **诊断链**（首次启动跑一次）：`诊断 Agent → 规划 Agent → 评价 Agent`
- **优化链**（学习中每次反馈触发）：`优化 Agent`

## 三、五大功能页详解

### 第 1 步 · 学生画像录入

**页面目标**：采集学生基本信息与学习偏好，作为后续诊断与路径规划的输入依据。

**操作流程**：

1. 填写**昵称**（必填）；
2. 选择**学习目标**（下拉可选 6 个常见管综目标，也支持自定义输入，如"2027 年管综数学过国家线"）；
3. 选择**认知水平**：初级（离校多年）/ 中级（有基础）/ 高级（系统学过），默认初级，贴近真实管综考生群体；
4. 拖动滑块设置**每日可用学习时间**（15–180 分钟，配 30/60/90/120 一键预设按钮，当前值实时显示）；
5. 选择**学习风格**：视觉型 🎨 / 听觉型 🎧 / 读写型 📝 / 动觉型 🎮（卡片式选择，附场景说明）；
6. 点击"下一步"进入**确认页**核对信息，确认无误后点击"创建画像并开始诊断"。

**产出**：在数据库 `students` 表创建一条学生记录，得到 `student_id`，自动跳转至诊断测验。

> **设计说明**：学科已锁定为"管综数学"（只读）；表单分两步降低认知负担；"学科 → 目标 → 认知水平 → 时间 → 风格"五项构成完整的画像向量。

---

### 第 2 步 · 诊断测验

**页面目标**：通过客观题作答，由诊断 Agent 量化学生在各知识点上的掌握程度。

**操作流程**：

1. 顶部选择**抽题数量**（5 / 10 / 15 题，可随时"重新抽题"，若已作答会弹确认避免误清空）；
2. 系统从题库随机抽题，**每道题取自不同知识点**以保证诊断覆盖面；
3. 逐题作答：题干支持 **LaTeX 公式渲染**（KaTeX），点击 A/B/C/D/E 选项作答；条件充分判断题会额外展示 ABCDE 选项含义说明；
4. 右侧**答题卡**实时显示作答进度——已答（绿色）、未答（虚线灰）、当前题（蓝框），可点击跳题；
5. 全部作答后点击"提交诊断"。

**提交后的多 Agent 处理**（带分阶段进度提示）：

| 阶段 | Agent | 工作内容 |
|------|-------|---------|
| ① 诊断 | 诊断 Agent | 综合答对率与用时，量化每个知识点掌握度（0–1） |
| ② 检索 | RAG | bge-m3 向量召回候选学习资源 |
| ③ 规划 | 规划 Agent | 结合先修关系与时间预算，生成个性化路径 |
| ④ 评价 | 评价 Agent | 对路径做五维客观打分 |

**诊断结果展示**：

- **四大模块掌握度雷达图**（算术 / 代数 / 几何 / 数据分析）——未测试的模块明确标注"未测试"，不误导为 0 分；
- **诊断 Agent 推理日志**——逐条说明判断依据；
- **路径质量评分卡片**——总分 + 五维条形图（针对性 / 顺序合理性 / 可行性 / 个性化 / 资源匹配），可展开查看亮点与改进建议；
- **详细知识点掌握度列表**——按掌握度升序排列，颜色区分已掌握 / 薄弱 / 极弱。

**产出**：写入 `mastery_snapshots`（诊断快照，保留历史）、`learning_paths`（最新路径）、`plan_evaluations`（评价留痕）。

---

### 第 3 步 · 学习路径视图

**页面目标**：以两种视图呈现规划 Agent 生成的个性化学习路径。

**视图一 · 路径列表（时间线）**：

- 以时间线形式逐项展示学习项，每项含：**序号、标题、预计时长、所属知识点、推荐理由**；
- 顶部展示**路径质量评分卡片**（与诊断页一致）；
- **每个路径项可点击**，直接跳转到学习工作台并定位到该项；
- 底部统计：学习项数、预计总时长、平均单项耗时。

**视图二 · 知识图谱**：

- 力导向图展示**知识点先修关系**（箭头表示"A 是 B 的先修"）；
- 节点颜色按掌握度区分：绿（已掌握）/ 黄（薄弱）/ 红（极弱）/ 灰虚线（未涉及）；
- 节点大小随掌握度变化，可缩放拖拽，悬停显示掌握度百分比。

**可解释性体现**：路径中每一项都有"为什么排在这里"的理由，例如"掌握度最低，是管综核心考点，优先夯实基础"。

---

### 第 4 步 · 学习工作台

**页面目标**：模拟学生按路径学习，并通过反馈触发优化 Agent 动态调整后续路径。

**操作流程**：

1. 顶部**学习进度条**显示"已完成 X / 共 N 项"；
2. **当前学习卡片**高亮显示正在学习的项（标题、知识点、时长、推荐理由）；
3. 可"标记完成"（完成项变绿划线），或点击"打开学习资源"跳转到匹配的视频/讲义（命中真实资源链接时可点击）；
4. 左侧**路径项列表**可点击切换当前学习项；
5. 右侧**学习反馈**：选择反馈类型并提交——
   - 😣 **卡住了** → 优化 Agent 插入针对性补强练习；
   - ✅ **已掌握** → 优化 Agent 跳过该节点；
   - ⏭️ **暂时跳过** → 移到路径末尾作为复习项；
6. 可填写补充说明（如"判别式总是算错"）让调整更精准。

**调整结果**：提交后优化 Agent 重新规划路径，弹出**调整通知卡片**，显示新增/删除项数与调整理由。用户可"接受调整"（采用新路径）或"保留旧路径"（忽略建议）。

**完成激励**：所有学习项完成后，显示**庆祝卡片**，汇总完成项数、累计学习时长，并引导查看评估看板。

**产出**：每次反馈写入 `interactions`（交互流水），优化后的路径 update 到 `learning_paths`。

---

### 第 5 步 · 评估看板

**页面目标**：以仪表盘形式回看学习全貌，量化呈现系统效果。

**展示内容**：

1. **路径质量评分卡片**（五维评分）；
2. **概览统计卡片**：学习路径项数、薄弱知识点数、已掌握知识点数、未涉及知识点数、预计总时长；
3. **掌握度分布柱状图**：横向条形展示各知识点掌握度，包含未涉及的知识点（灰条），呈现完整图景；
4. **Agent 推理日志**：按"诊断 / 规划 / 评价 / 优化"分类打彩色标签，完整记录决策链；
5. **学习路径明细表**：表格形式列出每项的知识点、学习内容、时长、推荐理由。

## 四、关键技术亮点（面向评审）

| 亮点 | 说明 |
|------|------|
| **多智能体可解释决策** | 4 个 Agent 协作，每步输出推理日志，全程可追溯，符合教育类 AI"可控、可解释、不误导"要求 |
| **RAG 真实资源匹配** | 规划时检索向量库，路径标题对齐真实资源并回填可点击链接，非凭空生成 |
| **闭环动态调整** | 学习反馈实时触发路径优化，区别于一次性推荐 |
| **双重评估体系** | 评价 Agent（LLM 主观五维）+ 客观指标（先修违反率、资源命中率等），互补佐证路径质量 |
| **mock 兜底机制** | LLM 不可用时自动降级到本地启发式，接口不中断，演示更稳健 |
| **数据持久化** | 8 张业务表落库，重启服务不丢学生路径；前端会话刷新不丢状态 |

## 五、演示建议路径

为在有限时间内完整展示闭环，建议演示顺序：

1. **创建画像**：填写一个典型在职考生画像（初级、视觉型、每日 60 分钟）；
2. **诊断测验**：抽 5 题，故意答对几题、答错几题，制造掌握度差异；
3. **查看诊断结果**：重点展示雷达图、推理日志、五维评分卡片；
4. **路径视图**：切换时间线与知识图谱两个视图，强调可解释理由与先修关系；
5. **学习工作台**：标记完成几项，提交一次"卡住了"反馈，展示优化 Agent 的路径调整；
6. **评估看板**：回看掌握度分布、推理日志全链路、路径明细。

> **演示提示**：诊断提交后会有约 20–30 秒的多 Agent 处理时间（带分阶段进度提示），属正常 LLM 调用耗时；如遇网络波动会自动 mock 兜底，可向评审说明此为稳健性设计。

## 六、后端 API 一览（技术附录）

| 端点 | 方法 | 功能 |
|------|------|------|
| `/profile` | POST | 创建学生画像 |
| `/profile/{id}` | GET | 查询单个画像 |
| `/concepts` | GET | 获取知识点列表（含先修关系） |
| `/questions/sample` | GET | 随机抽题（每知识点至多 1 题） |
| `/diagnose` | POST | 诊断 + 生成路径 + 评价（诊断链） |
| `/path/{id}` | GET | 获取最新路径（含评价、推理日志） |
| `/interaction` | POST | 提交学习反馈触发路径优化（优化链） |
| `/health` | GET | 健康检查 |
